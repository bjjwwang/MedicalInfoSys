运营与风险：用小闭环验证大故事

运营不是一开始铺全国、铺病种、铺数据资产。第一阶段应选择少量强需求病种、少量可信方案、少量真实老用户，验证“反馈能提高成交、订单能产生分润、分润能形成新反馈”的闭环。

运营核心：消费产生反馈，反馈提升信任，新消费再给老用户返佣。

1. 冷启动策略

阶段 运营重点 关键动作 成功信号
方案供给 先拿可信方案。 选择 3-5 个疑难病或慢病细分场景，签约愿意履约的医生/机构。 每个方案都有明确价格、服务范围、风险提示和负责人。
老用户背书 先拿真实反馈。 邀请已完成服务的患者提交脱敏反馈和关键指标摘要。 每个方案至少有 5-20 条可审核的真实反馈。
首批订单 小范围真实成交。 通过医生、患者社群、代理机构、推荐人 R 引入首批新用户。 新用户能看懂方案并愿意付款。
分润复盘 让账算得清楚。 生成第一批结算明细，向推荐人和老用户解释收益来源。 用户能理解“这笔钱为什么给我”。

2. 运营角色分工

方案招商

负责找医生、医院、专病团队，拿到可售方案、价格、履约流程和资质材料。

医学审核

审核方案、老用户反馈、风险提示和宣传文案，避免夸大疗效。

用户运营

维护新用户咨询、老用户反馈、社群沟通、收益解释和复购转化。

渠道运营

管理推荐人 R 和 B 端代理人，监控订单质量、退款率和违规宣传。

财务运营

结算批次、提现审核、税务材料、异常冻结和退款回滚。

风控客服

处理投诉、虚假反馈、刷单、诱导购买、收益争议和医疗服务纠纷。

3. 关键指标

指标类别 指标 为什么重要
供给 有效方案数、方案审核通过率、方案履约完成率。 判断商城是否真的有可买、可交付的商品。
转化 详情页转化率、老用户反馈点击率、支付转化率。 判断真实反馈是否提高购买信任。
分润 分润订单数、老用户池人数、平均老用户收益、提现成功率。 判断返佣机制是否真的有激励。
渠道 推荐人订单数、退款率、异常订单率、B 端代理反馈合格率。 防止渠道为了佣金牺牲服务质量。
风险 投诉率、退款率、虚假反馈率、收益冻结金额。 越早看到风险，越能避免模式变形。

4. 主要风险和处理

风险 表现 处理方式
老用户池稀释 方案越来越火，但单个老用户分到的钱越来越少。 MVP 先均分；规模起来后引入最近 N 名、时间窗口、质量阈值。
虚假反馈 机构或渠道找人伪造治疗经历以提高转化并拿分润。 必须有真实订单或真实服务记录；材料审核、抽查、违规清退。
多层分销变形 推荐人发展下线、承诺收益、用赚钱故事替代医疗服务。 系统只支持一级推荐；素材审核；违规冻结佣金和渠道。
医疗结果争议 用户认为购买方案后应保证疗效，引发投诉。 方案详情明确风险和适用范围；服务过程留痕；建立退款和争议流程。
隐私泄露 反馈内容含身份信息、原始病历被非授权查看。 脱敏展示、权限控制、敏感操作日志、后台导出管控。
账单不透明 老用户、推荐人、运营方不知道收益怎么算。 账单显示订单批次、分润类型、比例、冻结期和回滚原因。

5. B 端代理人运营

选择标准

优先选择真实接触患者、能提供服务、愿意合规留痕的医疗机构或服务组织。

培训内容

如何解释方案、如何取得授权、如何录入反馈、哪些话不能说、收益如何结算。

考核指标

有效反馈数、审核通过率、投诉率、退款率、违规素材次数、服务费争议。

退出机制

虚假反馈、诱导购买、伪造授权、多层返佣宣传，应暂停或终止合作。

6. 总裁待确认问题

  1. 分润比例是否按 70/15/10/5 试运行：方案运营方 70%，推荐人 R 15%，老用户池 10%，平台 5%。
  2. 没有推荐人时 15% 怎么处理：建议进入老用户池或平台营销池，需统一规则。
  3. 老用户池是否先均分：建议 MVP 均分，后续再加质量权重和时间窗口。
  4. 结算周期：建议 T+7 或每周清算，退款期内冻结。
  5. B 端代理服务费：建议从被代理老用户收益中按协议收取，例如 10%，不参与多级分销。
  6. 对外项目名称：底层定位保留“健康数据资产交易平台”（数据交易所备案口径），第一版对外以“疑难病诊疗方案商城”形式呈现；最终对外名称用哪种说法待总裁确认。

7. 推荐闭环

1

消费

现在用户购买方案，产生真实订单和服务履约。

2

反馈

用户治疗后提交有效反馈，进入老用户池。

3

背书

脱敏反馈展示在方案详情页，提高新用户信任。

4

新消费

新的用户因为可信背书购买同一方案。

5

再分润

新订单的一部分返给推荐人和老用户，闭环继续。

最终推荐表达：消费产生数据，数据经过授权、脱敏和审核后成为方案背书；后续消费再把一部分订单收入分给推荐人和老用户。第一版只做这个闭环。
